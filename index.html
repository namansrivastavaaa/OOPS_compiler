💻 How to Run Locally (Java & Python)

Execute code instantly with zero cloud delay by running the backend server locally on your machine:

🔗 GitHub Repository:
https://github.com/namansrivastavaaa/OOPS_compiler
  1. Make sure you have Node.js installed.
  2. For Java: Ensure JDK is installed (javac and java in PATH).
  3. For Python: Ensure Python 3 is installed (python in PATH).
  4. Clone the repository and navigate into it: 
    git clone https://github.com/namansrivastavaaa/OOPS_compiler.git
cd OOPS_compiler
  5. Install dependencies and run the backend server: 
    npm install
node Backend/server.js
  6. Open index.html in your browser and switch Server to Local in the top header!
