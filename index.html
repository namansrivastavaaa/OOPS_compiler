How to Run Locally (Java & Python)

To execute Java and Python code with zero cloud delay, run the local backend server on your machine:

  1. Make sure you have Node.js installed.
  2. For Java: Ensure JDK is installed (javac and java in PATH).
  3. For Python: Ensure Python 3 is installed (python in PATH).
  4. Open your terminal in the project directory.
  5. Start the server: node Backend/server.js
  6. In the top right of this page, switch Server to Local.
