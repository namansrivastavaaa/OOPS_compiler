How to Run Locally

To execute code locally without relying on the cloud, you need to run the backend server on your machine.

  1. Download server.js.
  2. Make sure you have Node.js installed.
  3. Ensure you have Java installed (javac and java available in your PATH).
  4. Open your terminal in the folder containing server.js.
  5. Run npm install express cors
  6. Run node server.js
  7. Select Local from the Server dropdown in the top right.
